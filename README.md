# Vue.js Tutorial

Projeto simples para estudar Vue.js 3, componentes e props.

## Requisitos

- Node.js e npm

## Como executar

```bash
npm install
npm run serve
```

Depois, abra no navegador o endereço exibido no terminal.

## Estrutura

- `src/App.vue`: componente principal da aplicação.
- `src/Header.vue`: componente de cabeçalho com propriedades para título, botão e cores.
